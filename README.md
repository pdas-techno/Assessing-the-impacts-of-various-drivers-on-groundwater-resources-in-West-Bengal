# Groundwater Level Analysis – West Bengal

## 📌 Project Overview
This project analyzes groundwater levels across different districts of West Bengal using SQL and Power BI. The dashboard provides insights into groundwater trends, water availability, and environmental patterns through interactive visualizations.

## 🛠 Tools & Technologies
- SQL
- Power BI
- Excel
- Data Visualization
- Data Cleaning

## 📊 Key Features
- District-wise groundwater analysis
- Interactive Power BI dashboard
- Trend and pattern visualization
- Environmental data insights
- Data-driven decision support

## 📂 Dataset Used
The dataset contains groundwater-related environmental and climate data collected for analytical purposes.
